# 📚 React: Desenvolvendo com JavaScript

Este projeto foi desenvolvido durante o curso **React: Desenvolvendo com JavaScript** da Alura. O objetivo é explorar conceitos fundamentais do desenvolvimento com React, como componentes, estados e propriedades, além de estruturar uma aplicação interativa.

🔗 [Acesse o projeto aqui](https://organo-omega-nine.vercel.app/)

## 📌 Visão Geral

- Desenvolvimento de um projeto interativo utilizando **React**.
- Uso de **componentes funcionais** e **hooks** para gerenciar estado.
- Estilização com **CSS Modules** para organização e reaproveitamento de estilos.
- Implementação de **props** para comunicação entre componentes.
- Organização e boas práticas no código.

## 🛠️ Tecnologias Utilizadas

- **React:** Biblioteca para criação de interfaces dinâmicas e reativas.
- **JavaScript (ES6+):** Utilização de recursos modernos da linguagem.
- **Vite:** Ferramenta para otimização e bundling da aplicação.
- **CSS Modules:** Estilização modular para maior organização e reuso.
- **npm:** Gerenciador de pacotes para dependências do projeto.
- **GitHub e Vercel:** Versionamento de código e deploy contínuo.

## 🚀 Como Rodar o Projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/davidtpires/organo-react.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd organo-react
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
5. Acesse o projeto no navegador através da URL informada no terminal.
